# Practice and spaced repetition

Practice mixes new words with scheduled reviews.

## Reviews

A round starts with up to five words. Misses return once at the end with shuffled choices. Only first answers count towards the score. Due reviews take priority over new words.

| Answer | Next scheduled review |
| --- | --- |
| Wrong or “I don't know” | At the end of the round |
| Correct on a scheduled retry | The next day |
| Later successful scheduled reviews | After 3, 7, 14 and 30 days, then every 30 days |

A scheduled word missed twice stays due for the next round. An extra retry from free practice preserves the original review date. A word remains eligible for review after it is marked learned.

“Learned” records a successful scheduled review after an earlier correct answer.

Each language saves the current and best run of consecutive correct answers across modes. A wrong answer or skip resets the run. Correction cards and daily replays leave it untouched.

## Daily words

Each daily set introduces four words, from easiest to hardest. At midnight in Lisbon, each set joins regular practice, even for players who missed it.

On unscheduled days, earlier sets loop in order as **Encore** or **Revisita**. A newly scheduled set takes priority. Web and Android use the same bundled calendar offline. Today's attempt and score are saved separately from practice.

The daily can be replayed for practice. Sharing uses the first result.

Finishing all four daily words in either language counts once per Lisbon calendar day, at any score. A missed day ends the current streak, and the personal best stays on the device.

## Evidence

Repeated retrieval improved delayed vocabulary recall in an experiment with word pairs. A separate spacing experiment found that the best review gap depended on how long the material had to be remembered. Neither study tested Matiz's multiple-choice game, level sizes or exact intervals. Those are pilot settings.

[Karpicke and Roediger](https://doi.org/10.1126/science.1152408) · [Cepeda et al.](https://doi.org/10.1111/j.1467-9280.2008.02209.x)

Highlighting an intact streak can encourage people to return. Matiz shows the personal best after a gap and keeps streaks separate from vocabulary mastery. [Silverman and Barasch](https://doi.org/10.1093/jcr/ucac029)
